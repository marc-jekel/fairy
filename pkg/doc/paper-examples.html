Reproducing the paper and its online supplement

Marc Jekel

2026-10-28

This vignette walks through the examples of Jekel, Regenwetter, Chen, and Line (in preparation), “Wait, what are you saying, exactly?” A theoretical framework for codifying and evaluating verbal hypotheses about proportions, and of its online supplement, one step at a time, with the code that produces each table and number. Every number quoted from the paper is also checked by the package’s tests (tests/testthat/test-paper-*.R).

The package does what “the mathematics fairy” does in the paper (it does not store the paper’s models; you enter them as constraint strings, as shown below) (https://modeling-for-everyone.eu/posts/fairy/):

In the paper In the package
minimal description via order constraints (H-representation) fairy_h(), fairy_constraints()
minimal description via extreme cases (V-representation) fairy_vertices(), fairy_words()
parsimony (volume) and the largest possible Bayes factor fairy_volume(), fairy_max_bf(), fairy_info()
overlap, nesting, mixture models fairy_intersect(), fairy_nested(), fairy_mixture(), fairy_compare()
replication models (identical, joint, substitutable) fairy_replicate()
input files for QTEST and multinomineq fairy_write_qtest(), fairy_write_multinomineq()

Part 1: The cringyness study

Verbal hypotheses become order constraints

Six probabilities describe the study. The probability that a randomly drawn child, teen, or adult cringes at an illogical joke or at a pun gives the order p1, ..., p6:

lab <- c("illogical: children", "illogical: teens", "illogical: adults",
         "pun: children", "pun: teens", "pun: adults")
data.frame(parameter = paste0("p", 1:6), meaning = lab)
#>   parameter             meaning
#> 1        p1 illogical: children
#> 2        p2    illogical: teens
#> 3        p3   illogical: adults
#> 4        p4       pun: children
#> 5        p5          pun: teens
#> 6        p6         pun: adults

A model is a character string. Constraints are separated by ;, chains such as p1 > p2 > p3 are allowed, and < and <= mean the same thing (as in the paper, models are closed sets, so no software can tell < from <=). The package does not come with the paper’s models: you enter them yourself. Here are Models 1 to 9 as constraint strings:

strings <- c(
  M1 = "(p1+p4)/2 < (p2+p5)/2 < (p3+p6)/2",
  M2 = "p1 < p2 < p3; p4 < p5 < p6",
  M3 = "p1 > p2 > p3; p4 < p5 < p6; p1+p2+p3 < p4+p5+p6",
  M4 = "p1 > p2 > p3; p4 < p5 < p6; p1 < p4; p2 < p5; p3 < p6",
  M5 = "p1 = p2 = p3 = p4 = p5 = p6",
  M6 = "p1 > p2 > p3; p4 < p5 < p6; p1+p2+p3 = p4+p5+p6",
  M7 = "p1 > p2 > p3; p4 < p5 < p6; (p1+p2+p3)/3 = (p4+p5+p6)/3",
  M8 = "{p1,p2,p3,p4,p5,p6} = {p1,p2,p3,p4,p5,p6}",
  M9 = "p1 < p2 < p3; p4 > p5 > p6; p1 > p4; p2 > p5; p3 > p6"
)
  • Model 1 is the average of the two joke types per age group, increasing with age.
  • Models 7 and 8 use approximate equality: approx_tol = 0.05 turns every equality into “within five percentage points”; it is passed to fairy_h() for these two models below.
  • Model 10, the mixture of Models 4 and 9, is not a string: it is built with fairy_mixture() below.
m <- lapply(strings, fairy_h, n_p = 6)                          # H-representations of Models 1 to 9
m$M7 <- fairy_h(strings[["M7"]], n_p = 6, approx_tol = 0.05)     # approximate equalities
m$M8 <- fairy_h(strings[["M8"]], n_p = 6, approx_tol = 0.05)
m$M10 <- fairy_mixture(m$M4, m$M9)                               # the mixture of Models 4 and 9
m <- m[paste0("M", 1:10)]
names(m)
#>  [1] "M1"  "M2"  "M3"  "M4"  "M5"  "M6"  "M7"  "M8"  "M9"  "M10"

Minimal descriptions via order constraints (Figure 2)

fairy_h() returns the non-redundant H-representation. For Model 4 the paper reports five inequalities among pairs of parameters and two range constraints, 0 <= p3 <= p2 <= p1 <= p4 <= p5 <= p6 <= 1:

fairy_constraints(m$M4)
#> [1] "- p1 + p2 <= 0" "- p2 + p3 <= 0" "p4 - p5 <= 0"   "p5 - p6 <= 0"   "p1 - p4 <= 0"  
#> [6] "p6 <= 1"        "- p3 <= 0"

The first line is the paper’s -1 x p1 + 1 x p2 <= 0. The same constraints in the machine-readable format of QTEST are written by fairy_write_qtest() (and for the R package multinomineq by fairy_write_multinomineq()):

fairy_write_qtest(strings["M4"], n_p = 6, file = "model4.tar")

The no-effect model (Model 5) is two inequalities and five equalities:

fairy_info(m$M5)[, c("dim", "inequalities", "equalities", "vertices")]
#>   dim inequalities equalities vertices
#> 1   1            2          5        2

The mixture model (Model 10) and its 64 constraints

The mixture of Models 4 and 9 says: each person follows either Model 4 or Model 9, with an unknown weight. Geometrically, that is the convex hull of the two models, and fairy_mixture() computes its H-representation:

mix <- fairy_mixture(m$M4, m$M9)
fairy_info(mix, volume = FALSE)
#>   dim vertices inequalities equalities volume max_bf
#> 1   6       12           64          0     NA     NA

There are 12 vertices and 64 non-redundant constraints. Twelve of them are the range constraints 0 <= p_i <= 1, which leaves the paper’s 52 order constraints:

hn <- rcdd::q2d(mix)
single <- rowSums(hn[, -(1:2)] != 0) == 1
c(range = sum(single), other = sum(!single))
#> range other 
#>    12    52

The first row of the paper’s list of 52 constraints reads p2 <= p1 + p3 <= 1 + p2. The package lists them too:

head(fairy_constraints(mix)[!single], 6)
#> [1] "p1 - p3 - p6 <= 0"             "p2 - p3 - p6 <= 0"            
#> [3] "p1 - p2 - p6 <= 0"             "- p3 + p4 - p6 <= 0"          
#> [5] "- p1 + p2 - p3 + p4 - p6 <= 0" "- p2 + p4 - p6 <= 0"

The paper counts the “edge cases” of the vertex V1 of Table 1 (p1 = p4 = p5 = p6 = 1, p2 = p3 = 0): it satisfies 26 of the 52 order constraints with equality, and 6 range constraints, 32 in all:

v1 <- c(1, 0, 0, 1, 1, 1)
slack <- hn[, 2] + as.vector(hn[, -(1:2)] %*% v1)
c(order_constraints = sum(abs(slack[!single]) < 1e-9),
  range_constraints = sum(abs(slack[single]) < 1e-9),
  total = sum(abs(slack) < 1e-9))
#> order_constraints range_constraints             total 
#>                26                 6                32

Out of the 2^6 = 64 corners of the unit cube, only 12 are allowed, so the mixture model is falsifiable.

Parsimony (Figure 3)

The parsimony of a model is its volume inside the unit cube of all conceivable families of Binomial parameters. The inverse of the volume is the largest Bayes factor the model can reach against the unconstrained model (uniform prior). Figure 3 of the paper has two rectangles, their overlap and a line segment:

I   <- fairy_h("p1 < .5; p2 > .25; p2 < .75", n_p = 2)
II  <- fairy_h("p1 > .3; p1 < .7; p2 > .5", n_p = 2)
III <- fairy_intersect(I, II)
IV  <- fairy_h("p1 = .5; p2 > .25; p2 < .75", n_p = 2)

rbind(I = fairy_info(I), II = fairy_info(II), III = fairy_info(III), IV = fairy_info(IV))
#>     dim vertices inequalities equalities volume max_bf
#> I     2        4            4          0   0.25      4
#> II    2        4            4          0   0.20      5
#> III   2        4            4          0   0.05     20
#> IV    1        2            2          1   0.00    Inf

Model I has area 0.25 (maximal Bayes factor 4), Model II 0.2 (5), their overlap Model III 0.05 (20). Model IV contains an equality, so it is a line segment with volume zero and no upper bound on the Bayes factor. The vertices of the overlap include two new ones that are not vertices of either rectangle:

fairy_vertices(III)
#>      p_{1} p_{2}
#> [1,]   0.3  0.50
#> [2,]   0.5  0.50
#> [3,]   0.5  0.75
#> [4,]   0.3  0.75

Model relationships (Table 3)

fairy_compare() returns the layout of Table 3: the diagonal gives each model’s volume, entries above the diagonal the volume of the overlap of two models, entries below the diagonal tell whether the row model is nested in (subset sign) or contains (superset sign) the column model, and otherwise the dimension of their overlap. The last row is the largest possible Bayes factor against the unconstrained model.

Where Table 3 of the manuscript and the package differ

A few entries of the printed table do not agree with the exact computation. We list them so that the table can be checked against the package output (all other entries, including the diagonal, the maxBF row, and the nesting and dimension entries, agree):

  • The overlaps of Model 10 with Models 2, 3, and 4 are printed as .01. Model 4 is nested in Model 10 (the table itself says so in the lower triangle), so their overlap is Model 4 itself, with volume 1/720 = 0.0014. The overlaps with Models 2 and 3 are 0.0028 and 0.0025.
  • Row 6 (Model 6), column 1 (Model 1) is printed as “nested in”, but Model 6 is not a subset of Model 1; their overlap is 5-dimensional.
  • Row 7 (Model 7), column 6 (Model 6): the package finds that Model 7 contains Model 6 (relaxing an equality can only add points), the printed table shows a 5-dimensional overlap. Row 10, column 3 is printed as 5-dimensional, but the overlap of Models 3 and 10 has positive volume, so it is 6-dimensional.
c(M6_in_M1 = fairy_nested(m$M6, m$M1), M6_in_M7 = fairy_nested(m$M6, m$M7),
  M3_M10_dim = fairy_dim(fairy_intersect(m$M3, m$M10)))
#>   M6_in_M1   M6_in_M7 M3_M10_dim 
#>          0          1          6

Replication models (Table 4)

With r = 3 labs, each with six probabilities, replication models live in 18 dimensions. fairy_replicate() builds the three versions of the paper:

  • identical: every probability is the same in all labs, 12 equalities, dimension 6, volume zero.
  • joint: each lab satisfies the model, labs are unrelated; the volume is the cube of the single-lab volume.
  • substitutable: each constraint holds whichever lab’s parameter is plugged in, for every term.

The columns of Table 4 are dimension, number of vertices, non-redundant inequalities, equalities, and the upper bound on the Bayes factor:

rep_table <- function(h, r = 3, bf_substitutable = NULL) {
  ident <- fairy_info(fairy_replicate(h, r, "identical"))
  joint <- fairy_info(fairy_replicate(h, r, "joint"))
  subst <- fairy_info(fairy_replicate(h, r, "substitutable"), volume = FALSE)
  subst$max_bf <- if (is.null(bf_substitutable)) NA_real_ else bf_substitutable
  out <- rbind(identical = ident, joint = joint, substitutable = subst)
  out[, c("dim", "vertices", "inequalities", "equalities", "max_bf")]
}

For Model 4 the substitutable bound has a closed form: the 18 values fall into six ordered groups of three, which happens with probability 3!^6 / 18!, so the bound is 18! / 3!^6. (For high-dimensional polytopes of this kind fairy_volume(method = "volesti") gives a stochastic estimate if the volesti package is installed.)

exact_sub <- factorial(18) / factorial(3)^6
rep_table(m$M4, bf_substitutable = exact_sub)
#>               dim vertices inequalities equalities       max_bf
#> identical       6        7            7         12          Inf
#> joint          18      343           21          0    373248000
#> substitutable  18       43           51          0 137225088000
format(exact_sub, scientific = TRUE, digits = 3)      # 1.37e11 in the paper
#> [1] "1.37e+11"
format(720^3, scientific = TRUE, digits = 3)          # "720^3 = 4e8" in the paper
#> [1] "3.73e+08"

Model 9 gives the same numbers:

#>               dim vertices inequalities equalities       max_bf
#> identical       6        7            7         12          Inf
#> joint          18      343           21          0    373248000

Part 2: The Heuristic-Systematic Model (online supplement)

Here are the theoretical predictions of the supplement, again entered as constraint strings. In the 2 x 2 design the four probabilities are PbW, PbS, PsW, PsS (p1 to p4): big or small gap, weak or strong argument. For the cue-congruence models the six probabilities PiW, PnW, PcW, PiS, PnS, PcS are p1 to p6.

hsm <- lapply(c(
  pred1    = "p1 < p2; p3 < p4",                                  # stronger arguments never hurt
  pred2    = "p1 < p3; p2 < p4",                                  # a smaller gap never hurts
  pred3    = "p1 < p2 < p4; p1 < p3 < p4",                        # both
  pred6    = "p1 < p2 < p3; p4 < p5 < p6; p7 < p8 < p9; p1 < p4 < p7; p2 < p5 < p8; p3 < p6 < p9",
  override = "p6 > p3 > p2 = p1; p6 > p4 = p5 > p2",
  tradeoff = "p6 > p3 > p2 > p1; p6 > p5 > p4 > p1; p5 > p2",
  ttb      = "p1 = 0; p4 = 0; p2 = 1; p5 = 1; p3 = 1; p6 = 1"    # take the best
), fairy_h)
hsm$override_ttb_mixture <- fairy_mixture(hsm$override, hsm$ttb)
lab4 <- c("big, weak", "big, strong", "small, weak", "small, strong")

Two populations

If Prediction 3 must hold jointly in two populations, the bound is 12^2 = 144. If it holds with substitutable parameters, it is 420:

  substitutable = fairy_max_bf(fairy_replicate(hsm$pred3, 2, "substitutable")))
#>         joint substitutable 
#>           144           420

A 3-by-3 design

Cue congruence: Override, Trade-off, and take-the-best

The six probabilities are PiW, PnW, PcW, PiS, PnS, PcS (incongruent, no, or congruent cues; weak or strong arguments). The Override Model (equation 7) contains two equalities and so has volume zero. Table A4 (top) lists its six extreme cases; take-the-best (bottom) is a single point:
